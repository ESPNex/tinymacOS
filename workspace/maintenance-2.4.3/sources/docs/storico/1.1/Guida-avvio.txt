tinymacOS 1.1 — Prisma                     GUIDA DI AVVIO
=========================================================
Sistema operativo sperimentale indipendente per x86-64. Non è macOS e
non esegue software Mac. Nessun browser o kernel Linux nel sistema guest.

1. CON IL KIT (Linux x86-64)
Estrai l'intero ZIP in una cartella scrivibile. Servono qemu-system-x86_64,
Python 3 e i file OVMF x64 CODE e VARS abbinati. Apri un terminale:

  cd tinymacOS-1.1
  ./run.sh

Lo script usa l'ISO inclusa e crea al primo avvio state/user.img (TinyFS,
8 MiB) e state/vars.fd. I documenti restano in user.img, NON nei file
ISO o VARS. Per usare altri percorsi firmware:

  OVMF_CODE=/percorso/OVMF_CODE_4M.fd \
  OVMF_VARS=/percorso/OVMF_VARS_4M.fd ./run.sh

Se manca un frontend grafico, usa ./run.sh -display vnc=127.0.0.1:0 e
collega un viewer VNC locale alla porta 5900. LIVE=1 ./run.sh avvia senza
disco dati: le modifiche di quella sessione vanno perse allo spegnimento.

2. CON LA SOLA ISO
Crea una VM QEMU PC (i440FX), x86-64, 1 CPU, 384 MiB RAM, VGA standard,
tastiera/mouse PS/2. Avvia dal lettore CD/DVD con OVMF x64, Secure Boot
disattivato. Non usare il BIOS legacy. L'ISO da sola funziona in RAM.
Per salvare: estrai SUPPORT/TINYFS.ZIP dall'ISO, poi estrai user.img e
collegalo come IDE primario master. In alternativa usa SUPPORT/MKDISK.PY
per CREARE un nuovo file marcato. Non collegare un disco fisico.

Esempio su Linux (nomi OVMF Debian; crea la copia VARS solo la prima volta):
  cp -n /usr/share/OVMF/OVMF_VARS_4M.fd prisma-vars.fd
  qemu-system-x86_64 -machine pc -accel tcg -cpu max -smp 1 -m 384 \
    -nic none -vga std -boot order=d \
    -drive if=pflash,format=raw,readonly=on,file=/usr/share/OVMF/OVMF_CODE_4M.fd \
    -drive if=pflash,format=raw,file=prisma-vars.fd \
    -cdrom tinymacOS-1.1-x86_64.iso \
    -drive file=user.img,format=raw,if=ide,index=0

3. DAL SISTEMA PRECEDENTE
A VM spenta, fai una COPIA del tuo user.img di TinyOS 1.0. Collega la
copia come disco dati della nuova VM; non riformattarla. Il mount conserva
i documenti e legge anche le preferenze a 3 byte. Per i nuovi manifest
.app occorrono quattro nodi liberi. Non avviare due VM sullo stesso file.

4. UN GIRO DELLA SCRIVANIA
- Ctrl+Spazio apre Cerca: digita un nome, frecce e Invio. Trova app e
  voci direttamente in Documenti. Ctrl+Maiusc+A apre la Libreria app.
- F1 Finder, F2 Terminale, F3 TextEdit, F4 Impostazioni, F5 Info,
  F6 Calcolatrice, F7 Calendario, F8 Monitor Attività, F9 Galleria.
  F10 mostra le finestre: clicca una miniatura per attivarla.
- Trascina la barra del titolo per spostare, l'angolo in basso a destra
  per ridimensionare; rosso chiude, giallo contrae, verde cambia zoom.
  Doppio clic sul titolo: zoom. Fai clic sull'icona nel Dock o premi il
  tasto funzione dell'app per ripristinare. Ctrl+M contrae, Ctrl+W chiude.
- I due cursori a destra nella barra aprono il Centro di Controllo.
  «Materiale: Opaco» disattiva il vetro; «Movimento: Ridotto» evita
  le transizioni. In Impostazioni puoi anche spostare il Dock a sinistra.
- Finder: selezione con clic, apertura con doppio clic o Invio. + Cartella
  e + File creano elementi; digita un prefisso per selezionare un nome.
  Spazio mostra una vista rapida in sola lettura del testo o della cartella;
  i menu File/Modifica agiscono sulla selezione.
- TextEdit: Ctrl+S salva; Ctrl+Maiusc+S sceglie il nome; Ctrl+O apre.
  Un nome senza slash iniziale è relativo a /Users/User/Documents.
- In Calcolatrice prova 12.5*4-8=; AC azzera. Operazioni in ordine di
  inserimento e fino a quattro cifre decimali, non algebra simbolica.
- In Calendario seleziona un giorno, poi Invio per la nota. Invio salva
  in Documents/Agenda/AAAA-MM-GG.txt. Frecce orizzontali: cambia mese.
- In Monitor Attività: Spazio mette in pausa, S cambia ordinamento. In
  Galleria: frecce per esplorare; Invio applica lo sfondo selezionato.
- La tastiera PS/2 usa la mappa USA; Ctrl e il tasto Super/Cmd (quando
  inoltrato alla VM) sono equivalenti. L'orologio legge l'RTC della VM.

5. PROVA DI PERSISTENZA
Con un disco collegato, in Terminale: write Documents/prova.txt Ciao Prisma
Poi: restart. Dopo il riavvio apri Terminale e digita: cat Documents/prova.txt
Per spegnere usa il menu tinymacOS o il comando off. Copia user.img solo
a VM spenta. TinyFS non è journaled: non usare come unica copia di dati.

Target verificabile: QEMU + OVMF. Nessun supporto promesso per hardware
fisico, GPU accelerata, rete, USB, audio, sospensione, SMP o app esterne.
