tinymacOS 1.2.2 «Aurora» — guida rapida
=====================================
Sistema sperimentale x86-64 indipendente: non è Apple macOS. Avvio UEFI
x64/OVMF, GOP, PS/2; riferimento QEMU pc, 384 MiB RAM, un core, VGA std.

Primo avvio: la mela bianca e la barra segnano il caricamento del kernel.
Scegli nome e password (8–64 caratteri ASCII stampabili). Usa Tab o Invio
per passare al campo successivo e conferma la password. Non c'è una
password predefinita. Ai riavvii è richiesta la password scelta.
Con il solo CD, l'account e i documenti vivono in RAM e non sopravvivono
al riavvio. Per conservarli avvia con il disco dati TinyFS dedicato.
Al login la verifica mostra uno spinner bianco a dodici tacche (non una
barra o un cursore colorato). La barra classica resta solo all'avvio.
Con movimento ridotto le tacche restano ferme. Il login non cifra il disco.

Aggiornamento da 1.2.1: spegni la VM, conserva il disco dati e sostituisci
solo il CD. Non ricreare user.img. Gli account esistenti usano la stessa
password. La nuova configurazione funziona anche senza RDRAND: se possibile
usa firmware, CPU o variabilità di temporizzazione controllata. Solo se
nessuna fonte è utilizzabile, compare «Codice di configurazione»: sul
computer host esegui `openssl rand -hex 16`, oppure con Python 3:
    python -c "import secrets; print(secrets.token_hex(16))"
Inserisci il risultato nel campo, premi Continua, poi scegli nome e password.
Su Windows puoi usare `py` al posto di `python`. Non riutilizzare il codice.

Dai sorgenti su Linux x86-64 con le dipendenze installate:
    ./build.sh
    ./run.sh
La build genera il CD fuori dal progetto, normalmente in
/tmp/tinymacos-<uid>/1.2.2/. TMC_BUILD consente una directory esterna diversa.
STATE indica dove tenere il disco utente e le variabili OVMF;
LIVE=1 ./run.sh avvia senza disco dati. ISO=/percorso/file.iso seleziona
un supporto esistente. Non collegare un disco fisico.

Da un altro hypervisor compatibile: collega il CD UEFI come ottico;
SUPPORT/TINYFS.ZIP contiene user.img vuoto (IDE primario master), oppure
crealo con python3 SUPPORT/MKDISK.PY user.img. Usa tastiera PS/2 US.
Non inizializzare nuovamente il disco se vuoi conservare i documenti.

Finder → Posizioni → Kernel avviato (o Ctrl+Shift+K in Finder).
/System/Kernel/kernel.elf è l'intero ELF caricato dal bootloader;
Avvio/BOOTX64.EFI è il loader. Sorgenti/ e kernel.map vengono dalla build.
Seleziona un file e premi Spazio, Invio o fai doppio clic: Vista rapida
legge l'originale, mostra dimensione e SHA-256. Frecce per le pagine,
Home/End per inizio/fine, Esc o Spazio per chiudere. Volume in sola lettura.
Terminale: shasum /System/Kernel/kernel.elf

F1 Finder  F2 Terminale  F3 TextEdit  F4 Impostazioni  F5 Info
F6 Calcolatrice  F7 Calendario  F8 Monitor Attività  F9 Galleria
F10 Panoramica, Ctrl+Spazio Cerca, Ctrl+Shift+A Libreria app.
Ctrl+M contrai, Ctrl+W chiudi; Ctrl+Shift+Q o menu mela → Blocca schermo.
L'accesso successivo riprende le finestre. Riavvia e Spegni chiedono conferma.
Aspetto chiaro/scuro, quattro sfondi, Dock laterale, trasparenza e riduzione
movimento sono regolabili. Nessuna ISO o credenziale è inclusa nei sorgenti.
